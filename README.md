# Präsenzlabor Betriebssysteme Wintersemester 2026/27

Dieses Repository dient im Wintersemester 2026/27 als begleitende Codesammlung zum **Präsenzlabor Betriebssysteme** an der Hochschule für Technik, Wirtschaft und Gestaltung (HTWG) Konstanz. Es stellt die für die Bearbeitung der Laboraufgaben benötigten Programme bereit.

## Grundlage

Die Aufgaben orientieren sich am Lehrbuch [Operating Systems: Three Easy Pieces (OSTEP)](https://pages.cs.wisc.edu/~remzi/OSTEP/) von Remzi H. Arpaci-Dusseau und Andrea C. Arpaci-Dusseau.

Die bereitgestellten Programme dienen dazu, die theoretischen Konzepte der Lehrveranstaltung praktisch nachzuvollziehen, zu untersuchen und zu vertiefen.

## Repository-Struktur

Das Repository ist nach Laborterminen gegliedert. Für jeden Termin gibt es einen eigenen Ordner, in dem sich die benötigten Programme befinden.
